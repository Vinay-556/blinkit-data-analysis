# 🛒 Blinkit Data Analysis Dashboard

## 📊 Project Overview

This project analyzes Blinkit's grocery sales data to understand sales performance, item-level trends, outlet performance, and customer ratings.

The raw grocery dataset was analyzed and transformed into an interactive Power BI dashboard to generate meaningful business insights and support data-driven decision-making.

## 🎯 Business Objectives

- Analyze overall sales performance
- Identify high-performing item categories
- Understand sales across different outlet types
- Compare outlet performance by location tier and outlet size
- Analyze the impact of item fat content on sales
- Evaluate customer ratings
- Identify sales trends based on outlet establishment year

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- DAX
- Data Cleaning
- Data Analysis
- Data Visualization

## 📈 Dashboard Analysis

### Sales Performance

The dashboard provides an overview of total sales and average sales while allowing users to filter the analysis by:

- Outlet Location Type
- Outlet Size
- Item Type

### Outlet Analysis

Sales performance is analyzed across:

- Outlet Establishment Year
- Outlet Size
- Outlet Location Type
- Outlet Type

The analysis shows that **Tier 3 outlets contribute the highest sales**, followed by Tier 2 and Tier 1 locations.

### Item Analysis

Item-level performance is analyzed across different product categories, including:

- Fruits and Vegetables
- Snack Foods
- Household
- Frozen Foods
- Dairy
- Canned
- Baking Goods
- Meat
- Soft Drinks
- Others

### Fat Content Analysis

Sales are compared between:

- Low Fat
- Regular

to understand their contribution to overall sales.

## 🔍 Key Insights

- Total sales generated across the dataset are approximately **$1.20M**.
- The dataset contains **8,523 items**.
- The average customer rating is **3.9**.
- **Tier 3 outlets generate the highest sales contribution** among the three location tiers.
- Fruits and Vegetables and Snack Foods are among the strongest-performing item categories.
- Outlet performance varies across different outlet types and sizes.
- Sales trends across outlet establishment years show variations in performance over time.
